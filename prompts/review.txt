2. Review every changed file. For each change, check:

   - **Regressions / Compatibility** -- broken workflows, changed output contracts, prompt placeholders, event/JSON formats, config shapes, CLI/help/version text, or automation markers
   - **Agent runtime contracts** -- MCP tool schemas, durable run/event ledger formats, policy-pack behavior, workflow presets, branch/base behavior, and PR metadata files

3. Prioritize findings in this order: correctness and regressions first, then resilience/security, then type safety, then style polish. Avoid opportunistic refactors.

4. If you find issues, fix them directly in the files.
