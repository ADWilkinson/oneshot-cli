The Pipeline

Six high-level phases from task to pull request, with automatic classification and a draft PR safety checkpoint under the hood.

1

Validate

git

Checks the repo exists and fetches latest from origin

2

Worktree

git

Creates an isolated worktree so the run stays off your main checkout

3

Plan

Claude

Reads the codebase, produces a structured implementation plan

4

Execute

Codex

Implements the plan following repo conventions

5

Review

Codex

Reviews the branch diff for bugs, types, and security before finalization

6

PR

Claude

Creates a draft PR first, then marks it ready after review fixes are pushed

Worktrees are cleaned up after every run. Your main branch is never touched.

Quick Start

1

Prerequisites

On your laptop

  • Bun
  • SSH access to your server

On your server

  • Bun
  • Claude Code
  • Codex CLI
  • GitHub CLI (authenticated)
  • ANTHROPIC_API_KEY and OPENAI_API_KEY in environment
2

Install

Install globally on both your laptop and server:

bun install -g oneshot-ship

Or from source:

git clone https://github.com/ADWilkinson/oneshot-cli.git
cd oneshot-cli && bun install && bun link
3

Configure

oneshot init

Walks you through SSH host, workspace path, API keys, and model preferences. Saves to ~/.oneshot/config.json.

Your repos on the server should be organized as <org>/<repo> under your workspace path:

~/projects/
  my-org/my-app/
  my-org/my-api/
4

Ship

oneshot my-org/my-app "fix the login timeout bug"

That's it. oneshot handles the rest.

Usage

oneshot <repo> "<task>"                 # ship a task
oneshot <repo> <linear-url>              # fetch ticket as context
oneshot <repo> "<task>" --bg             # fire and forget
oneshot <repo> "<task>" --local          # run locally, no SSH
oneshot <repo> "<task>" --model sonnet   # override model
oneshot <repo> --dry-run                 # validate only
oneshot init                             # configure
oneshot stats                            # recent runs + averages

Flags

Flag Short Description
--model -m Override the Claude model (e.g. sonnet, opus)
--dry-run -d Validate repo exists without running the pipeline
--local Run locally instead of over SSH
--bg Run detached in background (returns PID + log path)
--branch -b Base branch to use instead of main
--events-file Mirror JSONL events to an additional file
--help -h Show help
--version -v Show version

Examples

Basic usage

oneshot acme/api "add rate limiting to /auth endpoints"

From a Linear ticket

oneshot acme/api https://linear.app/acme/issue/ENG-142

Background mode

oneshot acme/web "migrate to React 19" --bg

Local execution

oneshot acme/api "fix typo in README" --local

Configuration

Created by oneshot init at ~/.oneshot/config.json:

{
  "host": "user@100.x.x.x",
  "basePath": "~/projects",
  "anthropicApiKey": "sk-ant-...",
  "linearApiKey": "lin_api_...",
  "claude": {
    "model": "opus",
    "timeoutMinutes": 180
  },
  "codex": {
    "model": "gpt-5.4-mini",
    "reasoningEffort": "xhigh",
    "timeoutMinutes": 180
  },
  "stepTimeouts": {
    "planMinutes": 20,
    "executeMinutes": 60,
    "reviewMinutes": 20,
    "prMinutes": 20
  }
}

Options

Key Required Description
host Yes * SSH target (e.g. user@192.168.1.10). Not needed with --local.
basePath No Root directory containing your repos. Defaults to ~/projects.
anthropicApiKey No Falls back to ANTHROPIC_API_KEY env var.
linearApiKey No Enables Linear ticket integration.
claude.model No Claude model for Plan + PR steps. Default: opus.
codex.model No Codex model for Execute + Review steps. Default: gpt-5.4-mini.
codex.reasoningEffort No Reasoning effort level. Default: xhigh.
stepTimeouts No Per-step timeout overrides in minutes.

Linear Integration

Pass a Linear issue URL instead of a task description to pull in full ticket context.

oneshot acme/api https://linear.app/acme/issue/ENG-142
1

Fetches issue title, description, and comments via GraphQL

2

Formats ticket as context for the planning step

3

Uses the issue ID for branch naming (e.g. ENG-142/fix-auth-timeout)

4

After PR creation, moves the ticket to "In Review" and comments the PR URL

Requires linearApiKey in your config.

Customization

CLAUDE.md

Drop a CLAUDE.md in any repo root to enforce conventions. oneshot reads it and passes it as context to both Claude and Codex at every step.

Use this for coding standards, architecture decisions, import patterns, testing requirements — anything you want the agents to follow.

Prompt Templates

Edit the prompt files to change pipeline behavior:

prompts/plan.txt How Claude explores and plans
prompts/execute.txt How Codex implements changes
prompts/review.txt How Codex reviews the diff
prompts/pr.txt How Claude creates the PR

Templates use {{variable}} placeholders replaced at runtime.

Agent Skill

oneshot is available as an Agent Skill for Claude Code, Codex CLI, Cursor, and other skills-compatible agents.

Install

npx skills add ADWilkinson/oneshot-cli

Or via ClawHub:

clawhub install oneshot-ship

Once installed, your agent uses it automatically when relevant, or invoke directly with /oneshot-ship.

oneshot zkp2p-clients

oneshot-ready

Bot enriches with context

PR opened

Autopilot ships it

The bot dispatches the enriched ticket to oneshot CLI. Minutes later, a PR drops in Slack.
