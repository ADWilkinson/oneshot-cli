## Summary
- Keeps local/background oneshot runs from mutating the caller checkout while the runtime works in its isolated temp worktree.
- Captures the source checkout branch and HEAD before pipeline execution, then fails loudly if either changes.
- Ensures PR branch checkout, push, and review finalization stay on the runtime-owned temp worktree branch.
- Adds regression coverage for source-checkout preservation and PR branch push behavior.

## Why
Local runs could accidentally switch or finalize against the source checkout passed to `--local`, leaving the caller repository on the wrong branch and risking an empty or detached finalization path.

## Changes
- Runtime isolation
  - Run background local child processes from `/tmp` instead of inheriting the caller working directory.
  - Snapshot and verify the source checkout branch/HEAD around local pipeline execution.
- PR finalization
  - Checkout the runtime PR branch inside the temp worktree before PR metadata generation.
  - Preserve PR branch metadata for review finalization and fail if the worktree is not on that branch.
- Agent prompts
  - Clarify that absolute source checkout paths are inspection context only.
  - Remove instructions that asked the PR agent to prepare or switch branches.
- Tests
  - Add fixture-based CLI coverage proving the source checkout branch/HEAD stays unchanged.
  - Add failure coverage for an attempted source checkout branch mutation.
